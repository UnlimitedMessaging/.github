# Unlimited Messaging

WhatsApp and email in one API — send messages, receive webhooks, build multichannel products without dealing with Meta.

**[unlimitedmessaging.app](https://unlimitedmessaging.app)** · [Docs](https://docs.unlimitedmessaging.app) · [Discord](https://discord.gg/danrEJV5Xx)

---

### What you can build

- Customer support inboxes (WhatsApp + email, one API)
- Automated messaging workflows and notifications
- AI agents that send and receive messages
- Delivery tracking, appointment reminders, transactional alerts

---

### Pricing

No per-message fees. Flat monthly rate. [Start free, no credit card.](https://app.unlimitedmessaging.app)

**Free**
Unlimited messages, email from your own mailbox, WhatsApp + email in one API request, web app + API access. Messages carry a small footer badge.

**Medium — €19/mo**
Everything in Free, no badge. Webhook message reception, WhatsApp number redirect, media and voice messages.

**Max — €29/mo**
Everything in Medium. Templating and dynamic variables, WhatsApp product sheets, advanced analytics with Excel export, unlimited recipients.
