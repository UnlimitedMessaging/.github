# Unlimited Messaging

WhatsApp and email in one API — send messages, receive webhooks, build multichannel products without dealing with Meta.

**[unlimitedmessaging.app](https://unlimitedmessaging.app)** · [Docs](https://docs.unlimitedmessaging.app) · [Discord](https://discord.gg/danrEJV5Xx)

---

### What you can build

- Customer support inboxes (WhatsApp + email, one API)
- Automated messaging workflows and notifications
- AI agents that send and receive messages
- Delivery tracking, appointment reminders, transactional alerts

### Stack

Go · Node.js · TypeScript · PostgreSQL · Next.js
